# Structure-coefficient theorem for evolutionary games on dynamic networks

# DESCRIPTION
This project is designed for the production of the paper titled Structure-coefficient theorem for evolutionary games on dynamic networks

## Implementation Details
- Data generation codes were implemented in **Julia 1.209.2**
- Figure plotting codes were implemented in **Matlab R2024a**

# FILE STRUCTURE

## Core Analysis Scripts
- `Structure_Coefficients_of_Dynamic_Networks.jl` - Computes structure-coefficients for given dynamic networks
- `Simulation.jl` - Monte Carlo simulation of strategy frequencies in given dynamic networks.
- `demo.jl` - An example
